# Simulador de intención de voto

Aplicación independiente y no oficial para simular el flujo de votación municipal y registrar intención de voto agregada.

Incluye:
- Intendente municipal.
- Listas de Junta municipal.
- Candidatos de Junta de Lista 1 (ANR) y Lista 2 (PLRA).
- Fotografías de referencia cargadas desde las capturas suministradas.
- Panel privado para administración y candidatos.
- Enlaces únicos de participación por candidato.

No es un sitio oficial del TSJE ni representa resultados electorales oficiales.
